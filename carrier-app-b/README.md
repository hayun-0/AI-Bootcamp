# 운송 파트너 앱 B안 (오더 보드형)

화물차 기사가 폐기물 운반 요청을 목록에서 고르고, 수락, 상차 검수, 운송, 정산까지 진행하는 콜 앱의 웹 시안입니다.

## 실행

`index.html`을 브라우저에서 열면 됩니다. 설치나 빌드는 필요 없습니다.

## 화면

| 화면 | 내용 |
|---|---|
| 홈 | 콜 받기 전환, 오늘 수입, 받을 수 있는 요청 |
| 운반 요청 | 검색, 운임순·가까운순·km당 운임 정렬, 목록과 지도 보기 |
| 요청 상세 | 공차·적재 경로, 운임 내역, 제한시간 안의 수락 |
| 운행 중 | 단계 진행, 마대 QR 검수(시연), 카카오맵 길안내 |
| 정산 | 기간 수입, 다음 정산, 운행 내역 |
| 마이 | 경로 계산에 쓰는 차량 조건 |

## 지도와 경로

- 인터넷에 연결되면 OpenStreetMap 실시간 타일을 쓰고, 연결이 없으면 내장 타일로 안산·시흥·화성 일대를 표시합니다.
- 경로는 `dijkstra.js`의 다익스트라로 브라우저에서 계산합니다. 도로 위 최단 시간 경로입니다.
- 내장 범위 밖 좌표는 Overpass API에서 도로를 받아 `roadnet.js`로 그래프를 만든 뒤 계산합니다.
- 일방통행을 반영하고, 전고 3.6m·총중량 12t 차량이 지날 수 없는 제한 도로를 뺍니다.
- 회전 제한과 실시간 교통은 반영하지 않으므로 시간은 추정치입니다.

## 시안의 한계

- 운임, 업체명, 수입은 예시 데이터이고 서버와 로그인은 없습니다.
- 공개 지도·주소·도로 서버는 시연용으로만 씁니다. 실서비스에는 별도 지도 업체나 자체 서버가 필요합니다.
