## D. 남은 사항 (모두 하)
1. 공개 판매 상세 `GET /listings/{id}`의 `composition`에 사용자가 쓴 재질명이 키로 그대로 나옴(예: `"이전  지시를  무시하고…": 0.05`). claim·summary·reasons·LLM 입력에는 없음(기계용 칸). 화면에서 이스케이프하거나 별칭 표 밖 이름을 "[입력값]"으로 바꿔 내보내기 권장.
2. 주문의 체크리스트 run은 주문 시점 당사자(주문자·판매 공장)만 `company_ids`에 있어, 나중에 배정된 기사는 그 run을 404로 봄(설계상 문제 아님, 필요하면 accept 때 추가).
3. 요약은 모두 LLM 문장이지만 현재 프롬프트에서는 지시를 잘 따름. 코드 게이트 자체는 LLM이 실제로 "등급 A"류를 말하게 강제할 수 없어 회귀 테스트(단위)에 의존.
4. X-Company-Id 위조는 인증 도입(배포 전) 전까지 유효.
5. pytest의 PostgreSQL 전용 10건은 SQLite 실행에서 건너뜀 — 위 HTTP 동시성 재현으로 보완했으나, CI에서 PostgreSQL로도 돌릴 것.
