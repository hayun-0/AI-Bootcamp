## 정상 동작한 것 (확인)
- 가입→AI 안내(LLM)→마대 3종 등급 A(0.97)/B(0.92)/C(0.85) 정확, "기름 묻은 장갑"을 items에 넣으면 통과증 보류와 이유 문구 정확.
- 대소문자·공백("Pp", " PP ")은 합쳐서 같은 PP로 계산, "500" 문자열 숫자 허용, 0/음수 kg는 400.
- 남의 마대 403, 통과증 없는 마대 400, 없는 마대 404, 헤더 없음 401, 남의 인계서 칸 403, 배정 안 된 회사 접근 403, 허가 전 재활용/운반 403(한국어 "운영자 허가 확인 전").
- 한 바퀴: 주문(418,000=1100×380 정확) → 콜 수락 → 수거 → 도착 → 검사 → 정산 → 인계서 3칸 → 번호 → 별점(rated). 5개 별점 중복 409, 자기평가 403.
- LLM 응답에서 규제 문구(법 제25조 등)는 근거가 붙어 있고 "앱은 제출하지 않는다" 안내가 사장님에게 이해되기 쉬움.

## 사장님 앱 화면에 빠진 엔드포인트
내 마대 목록·상세, 내 판매 목록(bundle_wait 포함)·판매 내리기/가격 수정, 내 주문 목록, 내 정보(/me)와 가입 때 고른 코드 후보 선택, 인계서 칸 내용 미리보기+재작성 안내, 검사 불합격 사유와 다음 선택, 받은/준 별점 목록, 재질명 선택 목록(표준 이름) 조회.

## 좋았던 점 3개
1. 등급 숫자와 통과증은 코드 계산으로만 나오고 LLM이 못 바꾼다 (위험 재질 items는 정확히 차단).
2. 한 바퀴 상태 이력과 정산 금액(418,000/120,000/0)이 계산식과 정확히 일치, 순서 위반은 일관되게 409.
3. 인계서 3칸 분리와 "올바로 값만 정리, 제출은 안 함" 안내가 법 근거와 함께 명확.

## 가장 먼저 고칠 것 3개
1. 재질명 표준화(피피/폴리프로필렌/PP 자투리→pp)와 "인식 못 한 재질" 안내 + 메모/위험어(기름·그리스 등)·waste_code 목록 검증으로 통과증 오발급 막기 (#1·#2·#4·#5).
2. 사장님용 조회 API(내 마대·판매·주문·불합격 사유)와 판매 내리기, 불합격 마대 재판매 길 (#8·#9).
3. AI 요약이 사실과 다르게 말하지 않게(등급 없음→"C등급" 등) 요약 후 의미 검증/템플릿 폴백 + 인용 꼬리표 제거 + 한국어 에러문구 + kg/금액 상한(500 방지) (#3·#6·#10·#12).
