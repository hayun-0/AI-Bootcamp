## 잘된 점 (여러 명 공통)
- 주문 선점·콜 수락: 동시 8요청에서 항상 1건만 성공(조건부 UPDATE)
- 남의 마대·판매·주문·인계서 접근 403, 몰래 넣은 필드(verified·금액·상태) 무시, SQL 주입 안전, API 키 노출 없음
- 등급·통과증은 코드 계산만, AI 주입 10건에도 등급 불변. AI가 꺼지거나 죽어도 거래는 계속(템플릿)
- 법 위험 권고 0건(자가 운반 유도 주입 무시), 시세 없는 품목은 "찾지 못함"

## 사용자 결정이 필요한 것
1. 운임 정하는 방식: (가) 구매자가 주문 때 운임 상한 제시 → 그 안에서만 수락 / (나) 운반업체 견적 → 구매자 승인 후 배차
2. 무게 차이 정산: 허용 오차(예: ±5%) 안이면 검사 무게로 비례 정산, 넘으면 자동 불합격·운영자 중재
3. 검사 불합격 처리: 운영자 중재 후 (등급 낮춰 재정산 / 처리비 받고 처리 / 반송) 중 선택
